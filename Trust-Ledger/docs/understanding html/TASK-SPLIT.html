🔗 How Frontend Connects to Backend

Frontend works fully with mock store right now. When backend is ready, swap store calls with fetch() calls — one line change per action.

Example — New Customer (currently mock → becomes real) 
// BEFORE (mock store):
const customer = addCustomer(formData);

// AFTER (real backend):
const res = await fetch('http://localhost:3000/customers', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(formData)
});
const { kycRef, txHash } = await res.json();
